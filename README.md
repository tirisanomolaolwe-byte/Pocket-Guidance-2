##  Project Overview
Pocket Guidance is a user-friendly personal budgeting app that helps users:
- Track expenses
- Manage budgets
- Monitor spending habits
- Stay financially disciplined

##  Features
-  User Authentication (Login/Register)
-  Add & Track Expenses
-  Dashboard with Total Spending
-  Category Management
-  Budget Goals + Alerts
-  Rewards & Gamification System

##  Tech Stack
- Kotlin
- Android Studio
- Jetpack Compose
- Room Database
- MVVM Architecture
- GitHub Actions (CI/CD)

## CI/CD
We implemented GitHub Actions to:
- Automatically build the project
- Run unit tests
- Ensure code stability on every push


## How to Run
1. Clone repo
2. Open in Android Studio
3. Run on emulator or device
